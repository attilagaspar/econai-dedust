Step 1 · erase table rules
Min rule length 22%
Minimum horizontal run length to erase (% of page width). Lower = shorter rules also erased.
Min vertical rule length same
Minimum vertical run length to erase (% of page height). Set lower than horizontal if column separators don't span the full page. 0 = same as horizontal.
Bridge dashes (px) 0 (off)
Before detection, closes gaps up to this many pixels in dashed/dotted lines so they are recognised as solid lines. 0 = off. Try 5–15 for dotted separators.
Erase thickness (px) 3
How many pixels around each detected line are painted white. Increase if thick borders leave remnants. Default 3.
Step 2 · binarise (paper → white, ink → black)
Instead of one global cutoff, each pixel is compared to its local neighbourhood. Handles faded ink and uneven paper tone. Uncheck to skip binarisation entirely.
Neighbourhood size 15
Pixel window used to compute the local mean (must be odd). Roughly match the height of one digit in pixels. Too small → noisy; too large → loses faint ink.
Sensitivity (C) 10
Subtracted from the local mean before thresholding. Higher = more pixels become white (aggressive background removal, may clip faint digits). Lower = more pixels kept black (preserves faint ink, but also more noise).
Step 3 · remove speckle noise (line detection)
Noise removal radius 2
Erases isolated black specks during line detection. 0 = off.
Step 4 · output image quality
Blur (σ) 0 (off)
Gaussian blur applied to the output image before OCR. Smooths salt-and-pepper noise. 0 = off.
Apply adaptive threshold to the final image fed to OCR. Gives clean black/white instead of grayscale — helps when background is uneven.
Output noise removal 0 (off)
Morphological opening on the final OCR image — removes remaining speckle noise. Works best after Binarize output is on. 0 = off.

⚖ Row rules

    

      Arithmetic rules between lattice columns, checked per internal row.
      Numbers refer to lattice column numbers (1-indexed); operators
      + − * / ( ) and exactly one =. Example: 1+2=4.
      Values are read from the best layer (Human > LLM > OCR > PDF).
      The third box holds the zero characters: a cell consisting only
      of these (any dash, underscore, dot…) counts as 0, and empty
      cells are always 0. Anything else that isn't a clean number makes the
      rule fail for that row. The last box is an optional page pattern
      of 1s/0s (e.g. 1,0,0) that cycles over pages — 1 = the rule
      applies, 0 = skip; blank = every page. Skipped pages show no violations
      and are skipped by Fix rule. Each saved rule appears in the Diagnose
      dropdown as ROW RULE: name; violating internal rows are shaded
      red on the page.
    

    

    
    

      
      
    

  







  

    
🛠 Rule fix

    

      Every violation of the active rule on this page is listed below. ▶ Ask LLM
      sends each violation's cell images and current readings (best layer per row)
      to the LLM with the prompt; proposed corrections appear as diffs.
      Each line has a checkbox (default checked). ✓ Apply checked writes the
      checked lines to the LLM layer (flagged 🛠 as rule-fixed) and removes
      them; unchecked lines stay so you can hit Ask LLM again for a fresh
      attempt. An existing Human value still wins by layer priority.

      bootstrap for training data, then fix in the editor.
